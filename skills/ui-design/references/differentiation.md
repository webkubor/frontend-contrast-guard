# 差异化细则

[ui-design](../SKILL.md) Step 1 的展开。目标：每个项目有自己的面孔，而不是"又一个 AI 生成的落地页"。

## 1. 竞品 / 同类扫描（3–5 个）

| 站点/产品 | 它们长什么样（色、字、版式、密度、动效） | 共性套路 | 我们刻意不同在哪 |
|---|---|---|---|
| … | … | … | … |

- 选同受众、同品类的真实产品，不选"设计灵感站"上的概念稿。
- 先提炼**共性套路**：这个品类人人都用的东西就是我们的背景板，不是我们的面孔。
- "刻意不同"要具体到可执行（例：同类都用冷蓝 + 卡片网格 → 我们用暖中性底 + 长文版式），不能写"更现代、更高级"。

## 2. 可记忆点（signature element）

每个候选方向必须有**一个**别人一眼认出的元素，例如：独特的标题字体处理、一种贯穿全站的形状语言、固定的强调色用法、特殊的网格/留白节奏、标志性的微交互。

- 一个就够；三个以上等于没有。
- 写清它出现在哪（首屏、导航、按钮、空状态…）以及不出现在哪，防止滥用。

## 3. 换名测试

把品牌名、Logo 换成同类任意一家：页面仍成立 = **不合格**。合格的方向至少在色彩、字体、版式、语气中两项上与品类共性明显不同，且能从定位推出来（为什么这个产品该长这样）。

## 4. AI 模板味检查（一票否决）

出现以下任一项即否决，**除非 DESIGN.md 明确写了选择它及原因**：

- 默认紫/靛蓝渐变、紫粉霓虹光晕；
- 居中 hero 大标题 + 副标题 + 两个按钮 + 下方三张等宽特性卡片；
- 通用 3D 插画 / 抽象 blob / 无意义渐变球；
- 全站同一种圆角大卡片 + 柔和投影的堆叠；
- Emoji 当图标、千篇一律的 "✨ Introducing…" 徽章；
- 所有区块同一节奏、同一对齐，没有主次。

## 5. 写进 DESIGN.md

结论写入 DESIGN.md「定位与差异化」小节：扫描表、共性套路、我们的差异、可记忆点、换名测试结论、被否决候选及原因。
