# 差异化细则

[ui-design](../SKILL.md) Step 1 的展开。目标：每个项目有自己的面孔，而不是"又一个 AI 生成的落地页"。

## 0. 颜色来源铁律：先查 Logo / Brand-Mark

在扫描竞品或拟定配色之前，先检查项目是否已有 logo / brand-mark（如 `brand-mark.svg`、`logo.svg`、`public/logo*`、`src/assets/*mark*`）：

- **已有 logo / brand-mark**：**整站色彩系统必须从 logo 推导，不得另起色系**（主色、品牌渐变、强调色与中性底倾向均须贴合标识色系）。
  - 例：`cs-ui-web` 从 `brand-mark.svg` 取框架靛紫 `#4F46E5 → #7C3AED`、破局青→天蓝 `#5EEAD4 → #22D3EE`；
  - 例：`blog` 从 `logo.svg` 取 graphite `#121416`、teal `#20c4b6` / `#4fe0d2`、orange `#ff8a3d`。
- **没有 logo / brand-mark**：才走 Step 1 竞品扫描与方向推导来确立色彩系统（或先确立标识再导色）。
- 色彩来源（logo 文件路径与提取色值，或"无 logo，从方向推导"）须如实写入 `DESIGN.md`。

## 1. 竞品 / 同类扫描（3–5 个）

| 站点/产品 | 它们长什么样（色、字、版式、密度、动效） | 共性套路 | 我们刻意不同在哪 |
|---|---|---|---|
| … | … | … | … |

- 选同受众、同品类的真实产品，不选"设计灵感站"上的概念稿。
- 先提炼**共性套路**：这个品类人人都用的东西就是我们的背景板，不是我们的面孔。
- "刻意不同"要具体到可执行（例：同类都用冷蓝 + 卡片网格 → 我们用暖中性底 + 长文版式；若项目已有 logo，色彩按第 0 节从 logo 推导，差异着力在版式、密度与信息结构），不能写"更现代、更高级"。

## 2. 可记忆点（signature element）

每个候选方向必须有**一个**别人一眼认出的元素，例如：独特的标题字体处理、一种贯穿全站的形状语言、固定的强调色用法、特殊的网格/留白节奏、标志性的微交互。

- 一个就够；三个以上等于没有。
- 写清它出现在哪（首屏、导航、按钮、空状态…）以及不出现在哪，防止滥用。

## 3. 换名测试

把品牌名、Logo 换成同类任意一家：页面仍成立 = **未通过**。

- **三轴与两轴门槛**：合格方向必须**至少在以下三轴中的两轴**上与品类共性明显不同，且差异能从产品定位推出来（为什么这个产品该长这样）：
  1. **配色结构**（主底色关系、极性、强调色系统；已有 logo 时从 logo 推导）
  2. **版式**（栅格体系、视觉主次、导航/Hero/模块排布）
  3. **密度 / 信息结构**（信息层级、留白节奏、每屏承载密度与阅读路径）
- **一轴不同即不通过**（例如只改了颜色、但版式和密度/信息结构仍与同类相同 = **未通过**；零轴不同更不通过）。
- **失败处置（严禁掩盖）**：
  - 未通过时必须**诚实写「未通过」**，指明雷同轴并写出**不改版的代价**（例如辨识度不足、换名后仍像品类模板、需靠品牌词或动效补区分），**不得用「通过」掩盖**。
  - 处置只有两条路：① 补足第二轴差异后重测；② 在决策卡如实披露「未通过」及代价，由 owner 明确拍板接受代价后继续。
- **反假断言**：任何自动化检查、评审脚本或测试断言，**不得写成必然通过的假断言**（如硬编码 `'通过'`、`assert.ok(true)` 或仅检查字段非空却不校验至少两轴差异）。

## 4. AI 模板味检查（一票否决）

出现以下任一项即否决，**除非 DESIGN.md 明确写了选择它及原因**（例如因项目 logo 原生使用靛紫色系，已在 `DESIGN.md` 写明 logo 来源路径与色值，且通过版式与密度/信息结构拉开差异）：

- 默认紫/靛蓝渐变、紫粉霓虹光晕；
- 居中 hero 大标题 + 副标题 + 两个按钮 + 下方三张等宽特性卡片；
- 通用 3D 插画 / 抽象 blob / 无意义渐变球；
- 全站同一种圆角大卡片 + 柔和投影的堆叠；
- Emoji 当图标、千篇一律的 "✨ Introducing…" 徽章；
- 所有区块同一节奏、同一对齐，没有主次。

## 5. 写进 DESIGN.md

结论写入 DESIGN.md「定位与差异化」与「视觉系统」小节：色彩来源（logo 路径或方向推导）、扫描表、共性套路、我们的差异、可记忆点、换名测试结论（通过的 ≥2 轴，或诚实写明「未通过」及代价）、被否决候选及原因。
